State markers

Each state has its own shape and a label, so none relies on colour alone.

Verified

From an API such as TMDB or Open Library. Shown quietly, a small check.

Unverified

From the web or entered by hand. A dashed ring, with the field underlined. Tap for the source.

Read from image

Taken from a screenshot. A small picture glyph, with the screenshot beside the card.
